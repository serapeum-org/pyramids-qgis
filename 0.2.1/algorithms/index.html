    Algorithms#

    Every algorithm is file-in / file-out — work is passed by file path, never by a live in-memory gdal.Dataset handle. They appear in the Processing Toolbox under Pyramids, split into the groups below.

    Each algorithm's own help text (the right-hand pane of its dialog) is the authoritative description of its parameters; this page is the map of what exists and what it maps to in pyramids.

    The Processing id column is what you pass to processing.run(...), e.g. processing.run("pyramids:raster_align", {...}). Most algorithms are CLI-backed: the plugin builds a pyramids <command> ... argument list and runs it in-process, so the command column is the pyramids CLI invocation behind the algorithm. The Mesh and Earth-observation groups call their library directly instead.

    There are 92 algorithms across 10 groups:

    Raster 33
    Vector 36

    Reproject raster collection pyramids:collection_reproject collection reproject
    Resample raster collection (temporal) pyramids:collection_resample collection resample

    Extract NetCDF group pyramids:nc_get_group nc get-group

    Select NetCDF time step pyramids:nc_sel nc sel

    Mesh#

    These wrap pyramids' MeshDataset directly rather than the CLI, since pyramids-mesh has no CLI. UGRID NetCDF is built in; other formats (2DM, Selafin, DFSU, XMDF, PLY, …) need pyramids-mesh installed.

    Algorithm Processing id pyramids API
    Convert mesh format pyramids:mesh_convert MeshDataset.read_file / to_file
    Mesh to vector pyramids:mesh_to_vector MeshDataset.to_geodataframe → FeatureCollection.to_file

    Earth Observation#

    These wrap pyramids-eo directly, since it has no CLI. They require pyramids-eo to be installed — it is a hard requirement for this group only.

    Algorithm Processing id pyramids API
    Contrast stretch (EO) pyramids:eo_stretch pyramids_eo.enhance.stretch
    Tasseled cap transform pyramids:tasseled_cap pyramids_eo.spectral.tasseled_cap

    Algorithm Processing id pyramids command
    Download STAC assets pyramids:stac_download stac download

    Process#

    Drive pyramids' own processing registry: apply a single tool, or run a whole pipeline.

    Algorithm Processing id pyramids command
    Apply processing tool pyramids:process_apply process apply
    Run processing pipeline pyramids:process_run process run

    Cloud Optimized GeoTIFF#

    A single algorithm, in its own toolbox group.

    Algorithm Processing id pyramids command
    Create Cloud Optimized GeoTIFF pyramids:cog_create raster cog create

    Example data#

    The repo ships a tiny, self-contained dataset under examples/data/ to try the algorithms on: a 32×32 EPSG:4326 DEM (dem.tif) and a polygon AOI (aoi.geojson). See examples/README.md for copy-paste processing.run(...) snippets.

    Not covered yet#

    • Terrain derivatives — slope, aspect and hillshade have no algorithm yet.
    • An interactive dock widget for COG preview / STAC browsing. The plugin is deliberately Processing-only today: it registers a provider and adds no toolbar, menu or panel.
