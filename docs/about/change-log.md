# Change-log

The project's change-log is generated by
[commitizen](https://commitizen-tools.github.io/commitizen/) from the Conventional Commit history on
each release (`cz bump`, run by the `github-release` workflow) and written to
[`CHANGELOG.md`](https://github.com/serapeum-org/pyramids-qgis/blob/main/CHANGELOG.md) at the repo
root. It is **not** edited by hand — any manual change is overwritten on the next release.

The first tagged release populates it from the commit history to date. Until then, see the
[commit history](https://github.com/serapeum-org/pyramids-qgis/commits/main) and the
[Releases page](https://github.com/serapeum-org/pyramids-qgis/releases) on GitHub.
